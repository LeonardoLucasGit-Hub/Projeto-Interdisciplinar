Sobre o projeto

 A ideia do projeto é juntar o que a gente aprendeu em PTIC, PC, MBD, GSO1 e IMC em um trabalho só, em vez de fazer uma entrega separada para cada matéria. Assim dá para ver na prática como as disciplinas se conectam.

Características

- Junta as matérias técnicas em um único projeto.
- É feito em equipe, com as tarefas divididas entre os cinco integrantes.
- Todos os arquivos ficam organizados em um só.
- Podemos usar IA para ajudar na construção mas com os prompts.
